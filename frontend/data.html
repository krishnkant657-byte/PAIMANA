Why there is no trained risk model

The ingested corpus covers four consecutive monthly reports. That yields three period-to-period transitions and no observed project completions, so there is no outcome label a supervised model could legitimately learn from.

A model trained here would either learn a rule that was written by hand (circular reasoning), or latch onto noise. PAIMANA therefore uses a fully deterministic engine in which every point of a risk score is attributable to a named driver backed by a source value. The conditions under which a learned model becomes defensible are set out in docs/ARCHITECTURE.md.
